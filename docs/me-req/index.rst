ME Requirements Specification
=============================

This document holds the requirements on the mechanical design of the robot arm: the assemblies,
the parts and the printed parts. The design that meets them is in the ME Design document
(``me-design``), the test cases that verify them in the ME Test Specification (``me-test-spec``).

.. note::

   No ME requirement yet. ``me-design`` held "Requirements and Design" until the V-model split
   (tiacsys/xdmod#69 decision Q8); it had no ME requirement to move. The ledger has no ``ME-REQ``
   ID yet.

What will go here
-----------------

* the ME requirements (``.. me-req::``), written as EARS sentences with value fields where they have
  a number (CK-E2, CK-E3);
* for each ME requirement, the system requirement or interface it refines (from the documents of
  robarm-syseng, which this build includes).
