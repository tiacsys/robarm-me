ME Test Report
==============

This document shows the results of the ME test cases of the ME Test Specification.

.. note::

   No results: there is no ME test case yet (``me-test-spec``).

What will go here
-----------------

* for each ME test case, its latest result (``TR`` needs, ``result of`` the ``ME-TC``), recorded
  from ``main`` or a baseline commit (D60) on the ``evidence`` branch of robarm-integration;
* the coverage of the ME requirements by passed tests.

The CAD findings of each assembly are not test results; they are in the assembly documents.
